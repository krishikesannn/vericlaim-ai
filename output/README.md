# Submission deliverables

This directory contains the curated, versioned hackathon handoff:

- `VeriClaim_AI_Analytics_Submission_Notebook.ipynb` - executed AI/analytics
  notebook;
- `VeriClaim_AI_10_Slide_Template_Followed_Deck.pptx` - final presentation;
- `external_models_evaluation.json` - reproducible external-candidate results.

Other generated decks, PDFs, inspection files and model copies are local build
outputs and are intentionally excluded from Git.
